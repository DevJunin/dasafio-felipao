## dasafio-felipao
//O que deve ser utilizado

-Variaveis (let)
-Operadores (+, -, /, *)
-laços de repetição(while, for, do while)
-estrutura de decisão (if, else if, else, switch case)

#Objetivo
Crime uma variável para armazenar o nome e a quantidade de experiência (XP) de um herói depois utilize um estrutura de decisão para apresentar alguma das mensagens abaixo:

Se XP for menor que 1000 = Ferro
Se XP for entre 1001 e 2000 = Bronze
Se XP for entre 2001 e 5000 = Prata
se XP for entre 5001 e 6000 = Ouro
Se XP for entre 6000 e 8000 = Platina 
se XP for entre 8001 e 9000 = Ascendete
Se XP for entre 9001 e 1000 =  Imortal
Se XP for maior ou igual a 10001 = Radiante

## Saída

Ao final deve se exibir uma mensagem:
"O Herói de nome **{nome}** está no nível de **{nivel}**
